# «Кадр» — тренажёр по базам данных для системных аналитиков

Интерактивный тренажёр школы AMP по модулю «Базы данных» на кейсе сети кинотеатров «Кадр»: реляционная модель, ключи и ограничения, нормализация, транзакции, ERD, проектирование данных под задачу, Data Dictionary, SQL на живой базе прямо в браузере, уровни изоляции, индексы и выжимка перед собеседованием.

После каждого ответа — **разбор на схеме**: интерактивная картинка показывает, как работает то, что вы выбрали, и где ломается неверный вариант.

Открыть: https://andreypol1991.github.io/kadr-trainer/

Прогресс хранится в браузере. Отчёт для преподавателя — кнопка «Отчёт».
